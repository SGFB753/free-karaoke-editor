КАРАОКЕ НА НОВОЙ ВИРТУАЛЬНОЙ МАШИНЕ — ПО ШАГАМ

Всё выполняется один раз. Занимает минут двадцать, из них
пятнадцать — скачивание библиотек.


ШАГ 0. КАКУЮ ВМ БРАТЬ
=====================

  Система   Ubuntu 22.04 или 24.04 (проще всего)
  Память    16 ГБ — работает всё
             8 ГБ — работает, кроме модели large-v3
             4 ГБ — только без минусовки, ключ --light
  Диск      20 ГБ
  Ядра      4, лучше 8
  Видеокарта не нужна; если есть NVIDIA — будет в 5-10 раз быстрее

Память — единственное, обо что спотыкаются. Минусовке нужно
около 4 ГБ, разметке small — около 2 ГБ.


ШАГ 1. ЗАЙТИ НА ВМ
==================

С Windows, в обычной командной строке (PowerShell):

    ssh пользователь@адрес-вм

Если ssh не находится — включите его:
Параметры -> Приложения -> Дополнительные компоненты ->
Добавить компонент -> Клиент OpenSSH.


ШАГ 2. ПЕРЕНЕСТИ ПРОГРАММУ НА ВМ
================================

Способ А. Скопировать с вашего компьютера.
В PowerShell у СЕБЯ (не на ВМ):

    scp -r D:\karaoke пользователь@адрес-вм:~/karaoke

Способ Б. Если папки под рукой нет — распакуйте архив
с программой прямо на ВМ:

    unzip karaoke.zip

Папку "проекты" переносить не нужно, она пересоздаётся.


ШАГ 3. ЗАПУСТИТЬ УСТАНОВКУ
==========================

На ВМ:

    cd ~/karaoke
    bash install-on-server.sh

Скрипт сам поставит ffmpeg, Python, создаст отдельное окружение
и подтянет библиотеки. Ключи:

    bash install-on-server.sh --gpu     есть видеокарта NVIDIA
    bash install-on-server.sh --light   без минусовки, экономно
    bash install-on-server.sh --models  сразу скачать модели

Ключ --models полезен, если хотите разом дождаться всех загрузок,
а не ловить их при первой песне.

Скрипт можно запускать повторно — уже установленное не ломается.

В конце он сам проверит, что всё встало, и напечатает,
что делать дальше. Если памяти мало — подскажет, как добавить
файл подкачки.


ШАГ 4. ЗАЛИТЬ ПЕСНЮ И ТЕКСТ
===========================

В PowerShell у СЕБЯ:

    scp "D:\karaoke\песня.mp3" "D:\karaoke\песня.txt" пользователь@адрес-вм:~/karaoke/


ШАГ 5. СОБРАТЬ
==============

На ВМ:

    cd ~/karaoke
    source .venv/bin/activate
    python3 app/karaoke.py "песня.mp3" "песня.txt" -o "караоке.html"

Первый запуск дольше остальных: качается модель Whisper.

Полезные ключи:

    --whisper-model medium   точнее, нужно ~4,5 ГБ памяти
    --whisper-model large-v3 лучшая точность, нужно ~8 ГБ
    --device cuda            считать на видеокарте
    --no-separate            без минусовки, вдвое быстрее

Видео:

    python3 app/tools/video.py "караоке.html"

Много песен разом — положите их в одну папку, назвав файлы
одинаково (Ветер.mp3 + Ветер.txt):

    python3 tools/auto.py ~/karaoke/песни


ШАГ 6. ЗАБРАТЬ РЕЗУЛЬТАТ
========================

В PowerShell у СЕБЯ:

    scp пользователь@адрес-вм:~/karaoke/*.html D:\готовое\
    scp пользователь@адрес-вм:~/karaoke/*.mp4  D:\готовое\


ЕСЛИ ХОЧЕТСЯ ОКНО СТУДИИ
========================

Студия слушает только сама себя и наружу не торчит — это
намеренно: паролей у неё нет, а файлы читать она умеет.
Добираться до неё нужно через туннель.

В PowerShell у СЕБЯ:

    ssh -L 8770:127.0.0.1:8770 пользователь@адрес-вм

В этом же окне, уже на ВМ:

    cd ~/karaoke && source .venv/bin/activate && python3 app/studio.py

Затем откройте у себя в браузере:  http://127.0.0.1:8770/

Порт студии в сеть НЕ открывайте.


НЕ СКАЧИВАЮТСЯ МОДЕЛИ
=====================

Модели тянутся из интернета при первом запуске: Whisper 75 МБ - 3 ГБ,
Demucs около 80 МБ. Программа скажет по-человечески, что именно
не скачалось, и продолжит без минусовки, если дело в ней.

Скачать заранее:   bash install-on-server.sh --models

Кэш лежит в ~/.cache/whisper и ~/.cache/torch/hub/checkpoints —
его можно перенести с другой машины и не качать снова.

ВАЖНО ПРО МИНУСОВКУ: кроме demucs нужен пакет soundfile. Без него
Demucs досчитает разделение и упадёт на записи результата. Скрипт
установки ставит его сам; вручную —  pip install soundfile


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
========================

Не хватает памяти (WinError-подобные сообщения, "not enough
memory", процесс убит) — добавьте файл подкачки:

    sudo fallocate -l 8G /swapfile
    sudo chmod 600 /swapfile
    sudo mkswap /swapfile
    sudo swapon /swapfile

Проверить, что цело:

    cd ~/karaoke && source .venv/bin/activate
    python3 tests/test_pipeline.py

Ждём "Все проверки пройдены".

Проверить по кускам:

    python3 -c "import stable_whisper; print('разметка ok')"
    python3 -c "import demucs, soundfile; print('минусовка ok')"
    python3 -c "from PIL import Image; print('видео ok')"


СКОЛЬКО ЖДАТЬ
=============

Песня 3,5 минуты:

    4 ядра, без видеокарты     ~5 минут
    8 ядер, без видеокарты     ~3 минуты
    с NVIDIA                   меньше минуты

С ключом --no-separate примерно вдвое быстрее.
