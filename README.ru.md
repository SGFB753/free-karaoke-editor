# Караоке из аудио и текста

*In English: [README.md](README.md)*

![Караоке-студия: сцена с текстом, сводка и дорожка](app/docs/studio.png)

> Короткая инструкция для начала — в файле **«app/START-HERE.txt»**.
> Здесь — полное описание всех возможностей.

Берёт аудиофайл песни и текстовый файл со словами — отдаёт **один HTML-файл**,
который открывается двойным щелчком в любом браузере на Windows, macOS, Linux,
Android и iOS. Интернет не нужен: звук, текст и тайминги лежат внутри файла.

```bash
python app/karaoke.py песня.mp3 текст.txt
```

## Что внутри готовой страницы

- Текст едет по центру, текущая строка крупная, слова заливаются цветом по мере пения.
- **Регулятор «Голос»**: 0 % — чистая минусовка, 100 % — оригинал, между ними — подсказка.
- **Кнопка языка** (`RU` / `EN`) — надписи переключаются на месте, выбор запоминается.
- Обратный отсчёт (три точки) перед вступлением после проигрыша.
- Клик по строке — перемотка к ней.
- Ползунок «Сдвиг» — подвинуть текст относительно музыки, если он спешит или опаздывает.
- Кнопка «Правка» — ручная разметка по тапам, если автоматика ошиблась.
- Экспорт `.lrc` и `.json`; правки сами сохраняются в браузере.
- Горячие клавиши: `Пробел` — пуск/пауза, `←` `→` — ±5 с, `↑` `↓` — сдвиг ±0,1 с,
  `F` — полный экран, `M` — вкл/выкл голос.

## Что лежит в папке

```
Install.bat  install.command    поставить (один раз)
Studio.bat   studio.command     открыть окно программы
README.md    README.ru.md       описание (английское / русское)
projects/                       ваши песни
app/                            сама программа
```

Больше в корне ничего нет. Внутри `app/`: код, `settings.ini`,
`START-HERE.txt`, серверные инструкции, проверки и `Make-karaoke.bat` /
`Make-video.bat` — для тех, кто любит перетаскивать файлы из проводника.
Песни лежат в `projects/` и при обновлении не трогаются: меняется только
папка `app`.

Имена папок с песнями пишутся латиницей: «Мамины Усы» → `maminy-usy`. Так они
одинаково открываются на любой системе, и в чужом проводнике не будет
крякозябр. Готовые файлы — HTML и MP4 — называются так же.

## Имена файлов и macOS

Файлы называются латиницей: `Studio.bat`, `Install.bat`, `settings.ini`,
`projects/`. Кириллические имена приезжали крякозябрами на нерусской Windows —
такой `.bat` просто не запускался. Старые имена программа всё ещё понимает:
если рядом лежит `настройки.ini`, он прочитается, а песни из папки `проекты`
не потеряются.

Для macOS рядом лежат `studio.command`, `install.command` и
`make-karaoke.command` — те же шаги, тот же питон, открываются двойным щелчком.
Отдельного `.exe` нет и не будет: программа должна одинаково работать на обеих
системах, а исходник — оставаться читаемым.

## Установка

Обязателен только **ffmpeg**:

| ОС | Команда |
|---|---|
| Ubuntu/Debian | `sudo apt install ffmpeg` |
| Fedora/RHEL | `sudo dnf install ffmpeg` |
| macOS | `brew install ffmpeg` |
| Windows | `winget install Gyan.FFmpeg` |
| Без прав администратора | `pip install imageio-ffmpeg` |

Всё остальное — по желанию, но сильно улучшает результат:

```bash
pip install stable-ts   # точная разметка по словам (нейросеть Whisper)
pip install demucs      # минусовка: отделяет вокал от инструментала
```

Обе библиотеки тянут PyTorch (~1–2 ГБ). Кроме того, **при первом запуске
скачивается модель Whisper**, и её размер зависит от `--whisper-model`:

| модель | размер | качество на русском |
|---|---|---|
| `tiny` | 75 МБ | черновое |
| `base` | 140 МБ | сносное |
| `small` | 480 МБ | хорошее |
| `medium` (по умолчанию) | 1,5 ГБ | очень хорошее |
| `large-v3` | 3 ГБ | лучшее, но медленно на CPU |

Без видеокарты `medium` считает примерно в реальном времени: 4-минутная песня —
около 4 минут. Если ждать не хочется, начните с `--whisper-model small`.

Без этих библиотек программа всё равно работает — см. «Как это работает».

## Запуск без командной строки (Windows)

В папке лежат ярлыки:

| Файл | Что делает |
|---|---|
| `Install.bat` | Разовая настройка: проверяет ffmpeg, предлагает поставить остальное |
| `Studio.bat` | Окно программы: сборка, правка, экспорт. Основной способ |
| `Make-karaoke.bat` | Перетащите на него песню и текст — получите HTML |
| `Whole-folder.bat` | Соберёт караоке для всех песен в папке разом |
| `Make-video.bat` | Перетащите готовую страницу — получите MP4 |

Порядок такой: один раз запустить `Install.bat`, дальше работать в Студии.
Ярлыки без окна остались для пакетной обработки и привычки.

Для пакетной обработки положите файлы в одну папку, назвав их одинаково:

```
Ветер.mp3   +   Ветер.txt    →   Ветер_караоке.html
Дорога.mp3  +   Дорога.txt   →   Дорога_караоке.html
```

Уже собранные песни пропускаются; чтобы пересобрать, добавьте `--force`.
Одна испорченная песня не останавливает остальные — в конце будет сводка.

## Студия

### Язык окна

Окно двуязычное: английский и русский. Кнопка `RU` / `EN` стоит в шапке рядом
с «Добавить песню» — надписи меняются на месте, выбор запоминается. Если его не
делать, язык берётся из строки `надписи` в `settings.ini`, а если и её нет —
из языка браузера. Названия языков песни («русский», «日本語») не переводятся:
их принято писать на них самих.

Готовая страница караоке переключается своей кнопкой, отдельно от окна.

`Studio.bat` (или `python app/studio.py`) поднимает локальный сервер и открывает
окно. Он слушает только `127.0.0.1` и проверяет заголовок `Host`, поэтому из
сети до него не достучаться.

Песни лежат в папке `projects/`: разметка в `project.json`, дорожки рядом.
Правки сохраняются на диск сами, пересобирать ничего не нужно.

Что можно делать со строкой:

| Действие | Как |
|---|---|
| выбрать | щелчок по строке или `↑` `↓` |
| поставить на текущую секунду | `Enter` или «⌖ Начало строки — сюда» |
| подвинуть на 50 мс | `[` и `]` |
| двигать мышкой | тянуть блок на дорожке, он прилипает к началу пения |
| растянуть | тянуть за правый край блока |
| **исправить опечатку** | «✎ Текст строки» или двойной щелчок — по строке на сцене либо по её блоку на дорожке; `Enter` сохраняет, `Escape` отменяет |
| **вставить забытую строку** | «＋ строка» — встанет после выбранной |
| **удалить лишнюю** | «− строка» |
| **отменить последнее** | `Ctrl+Z` или «↶ Отменить» |
| **скопировать ритм строки** | «⧉ Ритм» или `Ctrl+C` |
| **вставить ритм в другую такую же** | «⧉ Вставить ритм» или `Ctrl+V`; с галочкой «и все следующие» — во все последующие строки с тем же текстом |
| **дублировать строку целиком** | `Ctrl+D` |
| **вставить скопированные строки** | «⧉ Вставить строку» или `Ctrl+Shift+V` — копии встают **следом** за выделенным, ничего не затирая; расстояния между ними сохраняются, а если места мало, пачка ужимается |
| **выделить несколько строк** | **зажать и провести** по строкам — самый простой способ; либо `Shift`+щелчок и `Shift`+`↑` `↓` (подряд от опоры), `Ctrl`+щелчок (добавить одну). `Escape` снимает. Работает и на сцене, и по блокам на дорожке |
| **действие сразу по всем выделенным** | голос, «оригинал», удаление и вставка ритма работают по всей пачке |
| **удалить выделенную** | `Delete` или `Backspace` |
| **второй голос** | «◑ Голос» — строка переезжает на вторую полосу дорожки и красится вторым цветом |
| **оставить оригинал** | «♪ Оригинал» — на этой строке в караоке слышен голос из записи |
| **подвинуть отдельное слово** | тянуть жёлтый кусочек за середину |
| **задать длину слова** | тянуть кусочек за левый или правый край |
| **сдвинуть начало строки, не трогая конец** | тянуть блок за левый край |
| **растянуть конец строки** | тянуть блок за правый край |

Правка текста не трогает время строки: слова раскладываются внутри него заново
по слогам. Раскладка ровная, а поют неровно — поэтому у выбранной строки под
блоками показан ряд её слов.

Край строки трогает только крайнее слово: тянете правый край — растёт
последнее слово, левый — первое. Все остальные слова остаются ровно там же,
до миллисекунды. Выверенная разметка внутри строки от движения её краёв не
портится.

У каждого слова своё начало и своя длина, они не склеены встык: между словами
допустима пауза — в песне это норма. За середину слово двигается целиком, за
края задаётся его длина. Если слово наезжает на соседа, сосед уступает ровно
настолько, насколько наехали, и никогда не схлопывается в ноль. Крайние слова
могут растянуть саму строку; если строка при этом налезет на соседнюю, это
покажет панель «Проверить».

Всё сохраняется само. Надпись у названия песни показывает состояние: «не
сохранено» → «сохраняю…» → «сохранено». Выгрузка HTML и MP4 сначала дожидается
записи на диск, поэтому в файл попадает именно то, что видно в окне. Флажок «и все следующие» распространяет сдвиг на весь остаток песни —
это для случая, когда после соло уехало всё.

Обзор файлов открывается в последней папке, где вы были: отдельно для песен
и отдельно для текстов — они обычно лежат в разных местах. Если истории ещё
нет, открывается рядом с исходниками открытой песни.

На дорожке затенены места, где долго не поют — вступление, проигрыши, соло.
Строки туда попадать не должны, и на глаз это видно сразу.

Справа панель «Проверить». Она сообщает только о поломках: строка налезает на
соседнюю, слова внутри строки разъехались, строка начинается там, где вокала
не слышно, слогов больше, чем физически можно спеть. Долгая нота, распевка,
хвост в конце строки — это музыка, а не ошибка, и панель о таком молчит:
решает тот, кто слушает песню.

### Два голоса и цвета

Вокалы иногда идут внахлёст: основной голос и подпевка, чистый и экстрим.
Строке можно назначить второй голос кнопкой «◑ Голос» — или получить его
сразу, если строка целиком в круглых скобках.

Что это даёт:

- на дорожке в Студии появляется **вторая полоса**: блоки второго голоса
  уходят вниз и больше не наезжают на основные;
- на готовой странице такая строка подсвечивается **вторым цветом**;
- строки, звучащие одновременно, подсвечиваются **обе сразу**, а не по
  очереди — раньше видно было только ту, что началась последней.

Цвета выбираются квадратиками справа от кнопок на дорожке. Первая пара —
подсветка: основной голос и второй. Вторая пара — оформление: фон и цвет
букв. Всё это сохраняется в песню и попадает в HTML и в ролик. Для сборки из
командной строки есть `--colors` и `--theme`, для `settings.ini` — строки
`цвета` и `оформление`.

Буквы, которые сливаются с фоном, страница не примет: оттенок останется тем,
что выбрали, а светлота сдвинется, пока текст не станет различим (мерка
контраста та же, что в требованиях к доступности, — не ниже 4.5). Проверяется
и в Студии, и при сборке из командной строки.

### Один раз выверил — примени ко всем

Припев поют одинаково, а размечать его заново каждый раз — работа впустую.
Выверенную строку можно скопировать: **«⧉ Ритм»** запоминает раскладку слов
внутри строки, **«⧉ Вставить ритм»** накладывает её на выбранную строку с тем
же числом слов. Начало строки при этом не двигается — меняется только рисунок
внутри неё. С галочкой «и все следующие» ритм разойдётся по всем последующим
строкам с таким же текстом; на кнопке написано, сколько их нашлось.

Копируется всё выделенное: можно взять пачку строк и вставить её в другое
место — расстояния между строками сохранятся, а если места меньше, пачка
ужмётся пропорционально. Вставка именно добавляет строки, ничего не затирая;
если нужна только раскладка слов поверх существующей строки — это «⧉ Вставить
ритм».

`Ctrl+D` делает полную копию строки и ставит её сразу под оригиналом — вместе
с голосом, пометкой «оригинал» и разметкой слов. Если до следующей строки
места меньше, копия ужимается пропорционально, а не наезжает на соседа.

### Когда поют вдвоём

Если две строки звучат одновременно, читать общую кашу по центру невозможно.
Такие строки разводятся по сторонам: основной голос влево, второй вправо, у
каждой стороны своя цифра — 1 или 2 — и свой цвет. Сцена держит в центре
середину пары, чтобы обе строки были на виду.

В ролике то же самое: первый голос строкой выше, второй ниже, порядок
постоянный — строки не прыгают местами при смене «текущей».

### Кусок, который поёт оригинал

Иногда петь надо не всё. Подпевка, речь, реплика, важная для сюжета песни, —
такой кусок лучше оставить как в записи. Кнопка «♪ Оригинал» помечает
выбранную строку.

Что дальше:

- в **Студии** на дорожке кусок заштрихован, а в тексте у строки стоит
  «поёт оригинал» — при проигрывании там слышен голос;
- на **готовой странице** голос возвращается сам, чем бы ни был ползунок
  «Голос», и уходит на выходе из куска — плавно, без щелчка;
- в **ролике MP4** этот кусок сводится с вокалом, остальное остаётся чистой
  минусовкой.

Работает, если песня собрана с разделением дорожек: голос берётся из
отдельного вокала. Соседние отмеченные строки склеиваются в один кусок, чтобы
голос не мигал между ними.

## Долгие шаги

Разделение дорожек и разметка идут минутами. Чтобы окно не выглядело зависшим,
каждые 15–20 секунд в лог уходит отметка о том, что шаг жив:

```
Отделяю вокал от инструментала (htdemucs) — это самая долгая часть…
  …разделение дорожек: идёт 0:40 (Demucs: 67%)
Выравниваю текст по звуку…
  …выравнивание: идёт 0:30
```

Модели качаются один раз: Whisper в `~/.cache/whisper`, Demucs в
`~/.cache/torch/hub/checkpoints`. В Студии рядом с моделью написано, скачана
она уже или нет. Если загрузка сорвалась, программа скажет почему — нет сети,
побился файл, не хватило памяти — и доведёт сборку до конца без минусовки.

### Файл `settings.ini`

Чтобы не вписывать ключи каждый раз, ярлыки читают `settings.ini`:

```ini
движок = energy      # auto | whisper | energy
модель = small       # tiny | base | small | medium | large-v3
минусовка = нет      # да | нет  (нужен demucs)
кодек = mp3          # mp3 | opus | aac
```

По умолчанию там стоит быстрый режим — работает сразу, без загрузки нейросетей.
Когда поставите `stable-ts` и `demucs`, поменяйте на `движок = auto`
и `минусовка = да`.

### Слежение за папкой

```bash
python tools/auto.py D:\Музыка --watch
```

Программа будет ждать и собирать караоке для каждой новой пары файлов.
Остановить — `Ctrl+C`.

## Новый язык окна

Окно и готовая страница говорят по-английски и по-русски. Любой другой язык —
это файл JSON, без правки кода и пересборки:

1. Скопируйте `app/kstudio/messages/template.json` в `<код>.json` (`de.json`,
   `uk.json`, `pl.json`…).
2. Переведите значения. Пустое значение берётся из английского, так что
   недоделанный файл уже полезен.
3. Перезагрузите окно: кнопка языка перебирает всё, что нашлось.

Переводы через pull request — самый простой способ помочь.

## Ролик MP4 для YouTube

Без OBS и без записи экрана: кадры рисуются программно и передаются ffmpeg,
поэтому получается быстрее реального времени.

Проще всего — **перетащить готовую страницу на `Make-video.bat`**.
Можно перетащить и несколько сразу, и целую папку.

Если запустить ярлык без перетаскивания, он покажет список страниц рядом
и предложит выбрать номер (или `0` — обработать все).

То же самое из командной строки:

```bash
py tools\video.py "D:\Музыка\Песня_караоке.html"
```

Рядом появится `Песня_караоке.mp4` — 1920×1080, 30 кадров, H.264 + AAC,
`+faststart`. Заливается на YouTube как есть.

Прежде чем рендерить целиком, снимите пробник на 15 секунд:

```bash
py tools\video.py "...html" --start 45 --seconds 15
```

| Ключ | Что делает |
|---|---|
| `--audio minus` | минусовка (по умолчанию) |
| `--audio guide` | минусовка с вокалом на 35 % — удобно подпевать |
| `--audio original` | как в записи |
| `--timings t.json` | взять разметку, выгруженную из плеера |
| `--width / --height / --fps` | размер и частота кадров |
| `--crf 18` | качество: меньше число — лучше и тяжелее |
| `--font "C:\Windows\Fonts\arialbd.ttf"` | свой шрифт |

Нужна библиотека Pillow — её предложит поставить `Install.bat`.

Важно: правки разметки, сделанные в плеере, живут в браузере, а не в HTML.
Чтобы они попали в ролик, нажмите «Правка» → «Скачать тайминги» и **положите
скачанный файл рядом со страницей** — программа сама его подхватит и скажет об
этом. Либо укажите путь ключом `--timings`.

Про авторские права: ролик с фонограммой чужой песни почти наверняка получит
автоматическую заявку Content ID — даже с минусовкой, потому что она сделана из
оригинальной записи. Обычно это не блокировка канала, а перевод монетизации
правообладателю, но иногда включается блокировка по странам.


Во вступлении и в длинных проигрышах ролик показывает сверху отсчёт: сколько
осталось до ближайшей строки, какая она и полоска к её началу — то же, что
видно в Студии. Перерывы короче пяти секунд не отсчитываются.

Перед отрисовкой ролик печатает свой отчёт: песня, длина, строки, где поют
вдвоём, куски с оригинальным голосом, цвета, вид звука и число кадров. Не тот
файл или забытые пометки видно до долгой части, а не после неё.

Цвета и оформление ролик берёт из страницы: второй голос красится своим цветом,
а одновременные строки рисуются двумя рядами.
## Формат файла с текстом

Обычный `.txt` в UTF-8, одна строка песни — одна строка файла:

```
title: Название песни
artist: Исполнитель

[Куплет]
первая строка
вторая строка

[Припев]
строка припева
```

- `title:` / `artist:` в начале — необязательная шапка.
- Строка целиком в скобках — заголовок секции, он не поётся, а показывается как метка.
- Пустые строки игнорируются.
- Если у вас уже есть тайминги, можно дать готовый LRC — выравнивание пропустится:
  ```
  [00:12.30]первая строка
  [00:15.10]вторая строка
  ```

### Кто поёт и сколько раз

Голос можно задать прямо в тексте — не придётся потом расставлять его мышкой:

```
Обычную строку поёт первый голос
2: а эту — второй
(и подпевку тоже, она второй голос по умолчанию)

[голос 2]
Дальше всё поёт второй,
и это тоже,
[голос 1]
а здесь снова первый.
```

`2:` в начале строки — только для неё. `[голос 2]` (или `[voice 2]`) —
переключатель для всех следующих строк, пока не сказано иначе.

Повторы пишутся пометкой в конце строки:

```
Припев x4
Не остановить меня х2
```

Программа сама разложит строку на четыре — вручную выписывать не нужно.
Понимает `x4`, `×4`, `х4` (русская), в скобках тоже: `(x4)`. Число от 2 до 99.
Заголовок раздела при этом не размножается, а если тайминги проставлены
вручную в формате LRC, повторы не раскрываются — там у каждой строки своё
время.

### Скобки

`[Квадратные]` скобки на отдельной строке — заголовок раздела, он не поётся.

`(Круглые)` — строка песни, а не заголовок: так обычно записывают подпевку и
бэк-вокал. Такая строка поётся и на экране показывается скромнее основной —
мельче и курсивом. Исключение одно: `(Припев)`, `(Chorus 2)` и прочие
названия разделов узнаются по первому слову и остаются заголовками.

Раньше любая строка целиком в круглых скобках считалась заголовком и молча
пропадала из песни.

Такая строка сразу получает **второй голос** и свой цвет подсветки — см.
«Два голоса и цвета».

Знаки препинания сами по себе — тире, многоточие — не теряются: они прилипают
к соседнему слову и остаются на экране. Строка «Я — не я» так и показывается,
с тире.

## Как это работает

```
аудио ──► ffmpeg ──► demucs ──► вокал ──► выравнивание ──┐
                        └────► минусовка ────────────────┼──► HTML
                                        текст ───────────┘
```

1. **ffmpeg** приводит любой формат к общему знаменателю.
2. **Demucs** делит запись на вокал и минусовку. Разметка считается по чистому
   вокалу — это заметно точнее, чем по полному миксу.
3. **Выравнивание** — расстановка времени для каждого слова. Два движка:

   | Движок | Что делает | Требует | Точность |
   |---|---|---|---|
   | `whisper` | forced alignment: сопоставляет ваш текст со звуком нейросетью | `stable-ts` | по словам, ±0,1 с |
   | `energy` | ищет вокальные фразы по громкости и раскладывает по ним строки | ничего | по строкам, ±0,3 с |

   По умолчанию `--align auto`: берётся `whisper`, если он установлен, иначе `energy`.
   Движок `energy` не «размазывает» текст равномерно — он находит паузы между
   фразами и подбирает раскладку строк по фразам динамическим программированием,
   так что проигрыши и вступление учитываются.
4. **Сборка**: звук пережимается в mp3 и кладётся в HTML как `data:`-URI.

## Ключи командной строки

```
python app/karaoke.py АУДИО ТЕКСТ [-o ФАЙЛ.html]

разметка
  --align {auto,whisper,energy,none}   движок выравнивания
  --whisper-model tiny|base|small|medium|large-v3
  --lang ru                            язык текста
  --device cuda|cpu
  --timings timings.json               взять готовые тайминги (экспорт из плеера)

звук
  --no-separate                        не делать минусовку (быстро)
  --codec mp3|opus|aac                 mp3 — максимальная совместимость
                                       opus — файл в 2–3 раза меньше

вывод
  --no-embed                           не встраивать звук, положить файлы рядом
  --lrc                                дополнительно сохранить .lrc
  --title / --artist                   переопределить подписи
  --colors "#4de1ff,#ff8ad1"           цвета подсветки: основной голос и второй
  --theme "#0a0b14,#e8ebf5"            оформление: фон и цвет букв
  --ui-lang auto|en|ru                 язык надписей готовой страницы
```

## Примеры

```bash
# Быстрый черновик без нейросетей — секунды
python app/karaoke.py song.mp3 lyrics.txt --no-separate

# Максимальное качество
python app/karaoke.py song.mp3 lyrics.txt --align whisper --whisper-model large-v3

# Слабый компьютер: маленькая модель, компактный файл
python app/karaoke.py song.mp3 lyrics.txt --whisper-model small --codec opus

# Длинный концерт: не раздувать HTML, звук отдельными файлами рядом
python app/karaoke.py concert.flac lyrics.txt --no-embed
```

## Ручная правка одной строки

Когда проще указать время самому, чем ловить на слух:

```bash
py tools\fix_line.py timings.json --list
py tools\fix_line.py timings.json --line 34 --start 150.0
py tools\fix_line.py timings.json --find "первые слова" --near 135 --start 150.0
```

Время задаётся в секундах: `2:30` — это `150.0`.

Если под `--find` подходит несколько строк (припев ведь повторяется), программа
покажет их все с номерами и временем и **не станет угадывать**. Уточнить можно
номером `--line`, ближайшим текущим временем `--near` или порядковым `--nth`.

Слова едут вместе со строкой, промежутки между ними сохраняются. Ключ
`--and-after` двигает заодно все следующие строки — это для случая, когда
после проигрыша уехал весь остаток. Рядом кладётся резервная копия `.bak`.

Потом пересоберите песню с этим файлом через `--timings`.

## Если разметка съехала

Удобнее всего — в Студии (см. выше). В отдельной HTML-странице:

0. **«Правка»**, щёлкните нужную строку — она подчеркнётся и закрепится за
   правкой: песня играет дальше, а правится по-прежнему она. Доиграйте до места,
   где её начинают петь, и нажмите **«⌖ Начало строки — сюда»**. Кнопка «не эту»
   рядом снимает выбор.
1. Постоянное опережение или отставание всего текста лечит ползунок **«Сдвиг»**.
2. Не помогло — **«Правка» → «Начать разметку по тапам»**: включите песню и жмите
   `Пробел` в начале каждой строки. Слова внутри строки разложатся по слогам сами.
3. **«Скачать тайминги (.json)»**, и если хотите пересобрать страницу с этой разметкой:
   ```bash
   python app/karaoke.py song.mp3 lyrics.txt --timings timings.json
   ```

## Сводка после сборки

Отчёт нужен не только до долгой части. Когда песня собралась и открылась в
Студии, справа над списком «Проверить» стоит **Сводка**: длина, какая доля
песни занята пением, число строк и слов, места без пения, чем размечали, а
также сколько строк отдано второму голосу и сколько оставлено оригиналу.
Промежутки без пения кликабельны — попадаете прямо туда.

## Пока не поют

Во вступлении и в длинных проигрышах на сцене пусто, и по ней не понять, идёт
песня или встала. Сверху сцены — узкая полоска: сколько осталось до ближайшей
строки, какая это строка, и шкала, заполняющаяся к её началу. Текст она не
закрывает. После последней строки показывает, сколько до конца записи.

Мелкие перерывы не отсчитываются: пауза короче пяти секунд и так на виду, а
надпись, мигающая на полсекунды, только мешает.

Когда в окно дорожки не попадает ни одна строка, у её края появляется
подсказка: какая строка ближайшая и сколько до неё (или назад, если песня уже
допета). Пустая дорожка больше не выглядит сломанной.

## Отчёт перед сборкой

Сборка идёт минутами, а половина промахов видна заранее. Поэтому и в Студии
(как только выбраны оба файла), и в командной строке до тяжёлых шагов
печатается короткий отчёт:

```
Отчёт перед сборкой
──────────────────────────────────────────────
  Песня      Ветер.mp3
  Длина      3:42
  Без пения  0:00–0:14, 2:10–2:31
  Текст      34 строк, 187 слов, повторов: 12
  Разделы    Куплет, Припев
  Язык       русский (определён по тексту)
  Сделаю     минусовка, разметка Whisper (small)
  Займёт     около 13 мин (очень грубо)
```

«Без пения» — это вступление, проигрыши и соло: места, куда строки попадать
не должны. Для караоке это важнее темпа, поэтому в окне показано именно оно.
Темп тоже считается (автокорреляция нарастаний громкости с отбором по кратным)
и лежит в данных отчёта, но на виду его нет.

Оценка времени грубая и так и подписана: она построена на замерах одной
машины, у вас будет иначе.

Отчёт предупредит, если строк слишком мало на такую длину (обычно — не
выписаны повторы), если запись перегружена или наполовину состоит из тишины,
и если памяти меньше, чем нужно выбранной модели.

## Новая версия текста

Разбивку по строкам обычно правят уже после первой сборки — когда стало ясно,
как удобнее петь. Пересобирать песню ради этого не нужно: дорожки уже в
проекте, пересчитывается только разметка.

| Что случилось | Что нажать |
|---|---|
| поправили тот же файл `.txt` | **↻ Разметить заново** — он перечитывается с диска |
| текст лежит в другом файле | **⇄ Другой текст** — выбрать файл |

Новый файл запоминается как исходный, название и исполнитель из его шапки
подхватываются. Правки времени при этом заменяются: разметка считается заново.
Пустой файл отвергается с объяснением, песня остаётся целой.

## Своя минусовка

Если у исполнителя есть настоящий инструментал, он лучше любого разделённого.
В редакторе — кнопка **«♪ Своя минусовка»**: выбираете файл, и он встаёт
вместо разделённой дорожки. Разметка остаётся: пересчитывать нечего.

Официальный инструментал почти всегда начинается не там же, где сведённая
песня. Программа сравнивает громкости двух записей, находит сдвиг и двигает
всю разметку следом — в сообщении будет написано, на сколько. Если длина
заметно разошлась, об этом тоже скажут: конец стоит проверить.

Что происходит с голосом, зависит от того, как собиралась песня:

| Как собрана | Что с голосом |
|---|---|
| с разделением (Demucs) | готовый голос двигается на тот же сдвиг |
| без разделения | голос **выделяется вычитанием**: оригинал минус ваш инструментал |

Вычитание работает, когда инструментал от той же записи: тогда разница двух
дорожек и есть вокал. Программа сама подбирает громкость (по местам, где не
поют, обе дорожки должны звучать одинаково) и проверяет результат: если в этих
местах не стало тише хотя бы на 4 дБ, инструментал не от этой записи —
голос не выделяется, играет только ваша минусовка.

Вычитание идёт **по частотам**, а не одной громкостью. Официальный инструментал
почти никогда не сведён так же, как та же аранжировка внутри песни: другой
мастеринг, другая эквализация, другой уровень. Одним множителем это не
гасится — часть аранжировки остаётся в «голосе» и звучит рядом с минусовкой
как вторая, чужая запись. Поэтому множитель ищется свой для каждой полосы
частот: по местам без пения считается, какими усилением и сдвигом фазы
инструментал превращается в свою копию из песни, и вычитается уже исправленный.
На проверке это 29 дБ подавления аранжировки против 17 дБ у простого вычитания,
голос при этом цел (27 дБ сигнал/шум).

Чужая аранжировка по-прежнему отвергается: если в местах без пения не стало
тише хотя бы на 4 дБ, голос не выделяется, играет только ваша минусовка.

Оставлять оригинал «голосом», как раньше, нельзя: поверх нового минуса заиграла
бы вторая аранжировка. Именно это и слышится как «голос не совпадает».

Точность поиска сдвига — единицы миллисекунд: огибающая считается с шагом
10 мс, а вершина совпадения уточняется параболой между отсчётами.

## Язык песни

Whisper выравнивает текст с оглядкой на язык: с чужим разметка расползается.
В Студии язык выбирается рядом с моделью, по умолчанию — «определить по тексту».
Определение своё, не Whisper: по алфавиту и служебным словам. Выбранный язык
называется в логе сборки, так что видно, если угадали неверно.

```bash
python app/karaoke.py song.mp3 lyrics.txt --lang uk     # или auto, ru, en, de, fr…
```

В `settings.ini` — строка `язык = авто`. Понимаются 14 языков; для остальных
можно передать код Whisper напрямую, он пройдёт как есть.

Слоги, по которым раскладываются слова внутри строки, считаются точно только
для кириллицы. Для латиницы это эвристика по группам гласных, и на длинных
словах она ошибается — на разметку по словам от Whisper это не влияет, а вот
в режиме `energy` заметно.

## Память под модель

| Модель | Нужно памяти | Если меньше |
|---|---|---|
| `tiny` / `base` | 1–1,5 ГБ | работает почти везде |
| `small` | ~2 ГБ | обычный выбор |
| `medium` | ~4,5 ГБ | считает в разы дольше: система свопит |
| `large-v3` | ~8 ГБ | на домашней машине почти всегда не стоит |

Студия смотрит на свободную память и пишет рядом с моделью «тяжёлая для этой
машины», если её не хватает. Это не запрет — но ждать придётся долго, и это
не поломка, а именно нехватка памяти. При затянувшемся шаге лог сам это скажет.

## В контейнере

Если не хочется ставить PyTorch и всё остальное себе на машину — или просто не
хочется запускать программу из интернета вне песочницы:

```bash
cd app && docker compose up --build     # потом откройте http://127.0.0.1:8770/
```

Песни остаются в `projects/` рядом с запускалками, музыка для импорта — в
`music/` (монтируется только для чтения, создаётся при первом запуске). Модели скачиваются один раз в
именованный том, пересборка их не тянет заново. Порт открыт только на
`127.0.0.1`, как и при обычном запуске.

Без compose:

```bash
docker build -t karaoke app
docker run --rm -p 127.0.0.1:8770:8770 \
  -v "$PWD/projects:/songs" -v "$HOME/Music:/music:ro" karaoke
```

**Видеокарта.** Для NVIDIA поставьте на хост container toolkit и добавьте
`--gpus all` (или раскомментируйте блок `deploy:` в `docker-compose.yml`) —
Whisper и Demucs пойдут на карте. Без неё всё работает на процессоре, просто
дольше. Apple silicon в контейнер не пробрасывается вовсе — там быстрее обычный
запуск.

Запуск сам соберёт тестовую песню, поднимет Студию на свободном порту со свежим
проектом и приберёт за собой. Настоящие проекты он не трогает — папку задаёт
переменная `KARAOKE_PROJECTS`.

Важное про jsdom: он **ничего не рисует и не делает попаданий курсором**.
Поэтому беды вида «кнопка есть, но до неё не дотянуться» ловятся только слоями
на настоящем браузере — не убирайте их.

## Ограничения

- Whisper выравнивает по тому, что слышит: на шёпоте, крике и плотном миксе
  бывает промах. Минусовка через Demucs это заметно улучшает.
- **Программа не проверяет, что текст вообще от этой песни.** Forced alignment
  натягивает любой поданный текст на любой звук и всегда «успешно» завершается.
  Единственный признак — уверенность модели: если медиана ниже 0,08, в лог
  выводится предупреждение. Это подсказка, а не гарантия.
- Слоги в русском считаются точно (по гласным), в английском — эвристикой по
  группам гласных. На заимствованиях она врёт: `karaoke` даёт 2 вместо 4.
  Влияет только на относительную длину слов внутри строки.
- Разметка `energy` работает по строкам; отдельные слова внутри строки
  распределяются по числу слогов, а не по реальному звуку.
- Файл с длинной песней весит 4–8 МБ (mp3) — это нормально для `data:`-URI,
  но десяток таких страниц открывать одновременно не стоит.
- Автозапуск звука браузеры блокируют: первый раз нужно нажать «плей» руками.
- Текст правится только в Студии. В отдельной HTML-странице можно двигать
  времена, но не менять слова: страница уже собрана и звук в неё вшит.
- Отмена в Студии живёт в окне: перезагрузили страницу — история очистилась.
  Сами правки при этом на диске, они не теряются.

## Размер итогового файла

| Длина песни | mp3, одна дорожка | mp3, минус + вокал | opus, минус + вокал |
|---|---|---|---|
| 3 мин | ~2,5 МБ | ~5 МБ | ~1,8 МБ |
| 5 мин | ~4 МБ | ~8 МБ | ~3 МБ |

Opus меньше, но старые версии Safari его не открывают — mp3 надёжнее.
